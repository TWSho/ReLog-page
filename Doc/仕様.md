# ReLog 公式サイト仕様

更新日: 2026-11-12

## 目的

恋愛に限定せず、友達・家族・同僚・恋人など、人間関係全体の記録アプリとして紹介する。実装済みの機能だけを案内し、誤った配信リンクやプライバシー表現を掲載しない。

アプリの調査根拠は [実装確認.md](実装確認.md)。旧アプリ概要は歴史資料として区別する。

## ページ

| ページ | 内容 |
| --- | --- |
| `/` | コンセプト、関係の種類、タイムライン、人物プロフィール、繋がり、関係の変化、保存方針、FAQ、公開リンクの状況 |
| `/privacy/` | 入力情報、端末保存、CloudKit同期、運営者・AIサービスへの送信の有無、ホスティング・外部フォーム、削除、安全性、連絡先 |
| `/contact/` | 既存Googleフォームへの直接リンク、不具合報告時の案内 |
| `/en/`, `/zh/` | 各言語の同等ページ。日本語・英語・繁体字を維持 |
| `/404.html` | ホームへ戻れる404ページ |

公開時の全パスは `/ReLog-page/` 配下。旧 `#/privacy` / `#/contact` は日本語の静的ページへ移動する。

プライバシーポリシーは3言語とも運営者から利用者に向けた公開版として記述し、第三者の実装調査や開発段階の説明は載せない。外部ポリシーへのリンクはAppleのみ。Googleポリシーへのリンクは掲載しないが、お問い合わせで利用するGoogleフォームのデータ取り扱いに関する説明は維持する。

## デザイン

- 元のテーマカラー `#FF75B2` とホバー色 `#E55D9A` を維持。白と淡いピンクを基調にする。
- ロゴは元の `relog-site/public/icon_nobg.png` をそのまま使用。ヘッダー・フッター・ヒーロー・ファビコン・共有画像で統一し、別のマークに作り替えない。
- システムの明朝・セリフ体とサンセリフを使用。外部フォント通信なし。
- 余白のある構成と機能カードを維持。元のピンクの背景上には、可読性確保のため濃い文字を使う。
- 実アプリと異なる関係図・架空の人物・疑似画面は掲載しない。スクリーンショットは実際のアプリで撮影したものだけを使用できる。
- 実機素材が確認できるまではロゴと文章で紹介し、架空UIで代替しない。
- サイトからGitHubへの外部リンクは掲載しない。お問い合わせはGoogleフォームに統一。フッターには著作権表記のみを置き、追加スローガンは掲載しない。
- モバイルでは1列。ナビは隠さず折り返す。ハンバーガーの自前実装は設けない。

## 技術

- 最新Astro 7、TypeScript strict、静的生成。
- CSS Layers、Grid/Flex、clamp、prefers-reduced-motion、forced-colorsを使用。
- React、React Router、styled-components、i18next、Helmetは撤去。
- Astro標準のファイルルーティングとi18n URLヘルパー、公式sitemap integration。
- FAQはHTML `details/summary`。通常の閲覧と操作はJavaScript不要。
- 互換スクリプト以外のクライアントコード、送信フォームの独自処理、外部解析を追加しない。
- canonical / hreflang / OGP / Twitter Card / robots / PNG共有画像をビルド時生成。
- Node.js 22.23.4以上。依存はlockfileで固定。

## 品質と公開

- Astro型検査、Playwright（Chromium・モバイル・WebKit）、axe WCAG AA検査。
- JS無効の3言語、言語切り替え、FAQ、旧URL、404、内部リンク、画像、横はみ出しを検証。
- 3言語すべてで元ロゴの配信バイト一致、元のピンクのボタン、架空UIがないことを回帰テストする。
- GitHub Actionsで検証に成功したmainだけGitHub Pagesへ公開。
- 公開元の設定変更とgit pushは、利用者から明示的にデプロイを依頼された場合に実行する。お問い合わせフォームなどへのテスト投稿は行わない。
- 自動検査はアクセシビリティの完全な保証・専門家の認証ではない。
